# Compass HUD

A customizable compass HUD for Minecraft 1.21.1 (Fabric), featuring directional indicators and useful in-game information.

## Features

- Compass HUD with directional indicators
- Coordinates, biome, and in-game time
- Information about the targeted block
- Light level information
- Customizable HUD appearance

## Compatibility

- Minecraft: Java Edition 1.21.1
- Mod loader: Fabric

## Installation

1. Install Fabric Loader for Minecraft 1.21.1.
2. Install Fabric API if required by the mod.
3. Download `compasshud-1.0.0.jar` from the [Releases](https://github.com/W0lffoX/CompassHUD/releases) page, or from the repository.
4. Place the JAR file in your Minecraft `mods` folder.
5. Launch Minecraft using your Fabric installation.
